# 训练与合并配置

- `train_lora/` 是自定义训练 YAML/配套脚本，`merge_lora/` 是合并配置；先核对模型、模板、数据集、LoRA 阶段和执行环境，不改写上游同名配置来同步历史副本。
- 数据集 key 必须存在于 `../data/dataset_info.json`，更新登记前读 [data 规则](../data/AGENTS.md)。模型、数据、输出路径保留环境语义，运行前检查实际可用性与输出隔离。
- 配置修改用 YAML 解析、登记/模板引用核对与 Shell `bash -n` 验证；这不代表训练效果已验证，不自动启动 GPU/付费任务。
- 改参数解析/实现时转读 [框架规则](../src/AGENTS.md)；同步上游保留个人新增配置，历史范围见根同步说明。
